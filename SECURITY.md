# Security Policy

[English](SECURITY.md) | [日本語](docs/ja/security.md)

## Supported versions

Security fixes are applied to the latest v1.0.0 source on the default branch. Older commits and locally modified exports are unsupported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory flow for this repository, including a minimal reproduction, affected version or commit, impact, and any suggested mitigation. If that flow is unavailable, contact the repository owner privately through the contact method listed on the GitHub profile.

Do not include credentials, private skill contents, or local absolute paths in the report. We will acknowledge a valid report, assess its impact, and agree on a disclosure timeline before publishing details.
