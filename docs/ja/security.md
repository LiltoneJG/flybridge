## サポート対象バージョン

セキュリティ修正は、デフォルトブランチ上の最新の v1.0.0 ソースに適用されます。それ以前のコミットおよびローカルで変更されたエクスポートはサポート対象外です。

## 脆弱性の報告

脆弱性の疑いを public issue として報告しないでください。このリポジトリの GitHub private security advisory を使用し、最小限の再現手順、影響を受けるバージョンまたはコミット、影響、および考えられる緩和策を記載してください。この機能を利用できない場合は、GitHub プロフィールに記載された連絡方法を使って、リポジトリ所有者へ非公開で連絡してください。

報告には認証情報、非公開 skill の内容、ローカルの絶対パスを含めないでください。有効な報告を受領したことをお知らせし、影響を評価したうえで、詳細を公開する前に開示時期を合意します。
